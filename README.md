## Опис проєкту
Проєкт створено в межах виконання лабораторної роботи №3 для опанування інструментів GitHub та ведення технічної документації.

Програмна система автоматизує роботу міської лікарні: запис пацієнтів на прийом, електронну медичну картку, облік госпіталізацій і ліжкового фонду, лабораторні аналізи та звітність для керівництва.

## Основні модулі
1. Реєстратура та запис на прийом
2. Електронна медична картка
3. Стаціонар (госпіталізація, ліжковий фонд)
4. Лабораторія
5. Призначення та медикаменти
6. Кабінет пацієнта
7. Звіти
8. Інтеграція з ЕСОЗ
9. Адміністрування
